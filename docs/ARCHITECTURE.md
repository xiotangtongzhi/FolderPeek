# 目录浮窗的工作流程

1. `ExplorerFollower` 在独立 STA 线程中运行定时器，约每 650ms 检查窗口顺序，排除隐藏、最小化和非资源管理器窗口。
2. 使用 Windows Shell / COM 接口确认活动文件夹路径；不依赖窗口标题推测路径。
3. `MainForm` 调度后台目录读取，通过取消信号和读取代次丢弃过期结果。
4. `DirectoryPager` 枚举当前目录；`MapSnapshot` 统计直接子文件夹与文件，保留排序后的可见条目，按设置的深度扩展可见分支。
5. 默认每文件夹 5 项；每个分支拥有独立的显示数量。「展示更多」只增加该分支的数量。
6. `MapCanvas` 将节点映射为坐标和分支线，绘制文字、层级颜色、选择状态；平移与缩放作用于画布。
7. `Theme`、`MixedText` 和 `L10n` 分别处理主题、混合字体和界面语言；`SettingsStore` 保存本地 XML 设置。

全局节点预算为 2,500；可选展开深度为 1、2、3、5、8、12。链接/云目录等重解析点子节点不自动递归。对没有权限、已删除或暂时不可用的目录显示可读的错误。

为了获得当前目录的准确数量，需要枚举该目录的直接条目；即使只显示 5 项，也并不意味着只读取 5 条目录项。程序避免的是对所有隐藏分支进行全量递归。

目录浏览在本地进行，不需要读取文件内容。Ctrl+单击文件仅请求资源管理器定位，不执行文件。
