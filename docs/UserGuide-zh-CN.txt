目录浮窗 Folder Peek v1.5

作者：TTang
邮箱：lim822190@gamil.com
工作邮箱：tzw822190@nwafu.edu.cn

适用系统：Windows 10 / 11，需 .NET Framework 4.8 或更高版本。
安装到当前用户，无需管理员权限。可在 Windows 设置的应用列表中卸载。
中文和英文安装包是同一应用的两种语言版本；安装另一语言会替换界面语言。

打开资源管理器并切换文件夹，浮窗会跟随最前面的资源管理器窗口。
也可点击“选择文件夹”，或在路径栏输入完整路径并回车。
每个文件夹默认显示 5 项；点击“展示更多”追加 5 项。
右键可调整每次数量。展开深度控制自动展开的层数。
鼠标中键拖动画布；滚轮上下移动；Shift+滚轮横向移动；Ctrl+滚轮缩放。
双击文件夹聚焦；Ctrl+单击在资源管理器中打开或定位。
太阳/月亮按钮切换日间和夜间模式。
路径下方的三角按钮隐藏顶部名称、工具栏和路径，目录树保持显示；再次点击恢复。
顶部隐藏时可拖动三角旁的空白区域移动窗口。Alt+F4 关闭，F5 刷新。

设置保存于 %LOCALAPPDATA%\FolderPeek\settings-v1.5.xml。
卸载保留个人设置，不删除浏览的文件。软件不收集或上传目录数据，不设置开机自启。
本发布包尚未进行代码签名，Windows 可能显示未知发布者提示。
系统文件夹选择对话框的部分文字由 Windows 显示语言决定。
